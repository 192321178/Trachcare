TrachCare

The whole app, redesigned

Modern clinical calm — deep teal and mint on near-white, soft shadows, 20 px cards. Every screen of the Patient, Doctor and Admin flows, exported at 390 × 844.

37 screens3 roles390 × 844 Figma-ready layersFlutter · Material 3

Design direction

One teal family carries all three roles, with violet reserved for Admin so staff screens never read as patient screens. Type is Plus Jakarta Sans throughout.

How it was built

Tokens live in lib/style/design_system.dart and the widget kit in lib/components/ui_kit.dart. These images come from the same values, regenerated by figma-import/gen/build.py, so the page cannot drift from the app.

For designers

The figma-import/svg-src folder holds the same 37 screens as layered SVGs — import them straight into Figma and every group and text run stays editable.
